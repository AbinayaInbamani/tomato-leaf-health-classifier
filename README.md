# Tomato Leaf Health Classifier

A Streamlit app using a frozen OpenCV + KNN model trained on balanced PlantVillage tomato leaf images.

## Files
- `streamlit_app.py`
- `requirements.txt`
- `model_output/model_config.json`
- `model_output/tomato_leaf_health_model.joblib` (add this from your Colab training output)

## Run locally
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```
